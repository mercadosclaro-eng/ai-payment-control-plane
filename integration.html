STABLE CONTRACT

Three outcomes an agent can act on.

01

ALLOW

The declared intent passes current policy. The signer must still verify that the payment matches the checked intent.

02

BLOCK

Stop execution. The response includes reason codes and a receipt for the attempted action.

03

REQUIRE_APPROVAL

Pause execution and route the intent to the owner or an approved human workflow.

QUICK START

Use a separate credential for each agent.

Register an isolated free client credential, keep its administration token outside the model, and send the client token only with API or MCP calls.

1. POST /register
2. Store the returned administration credential outside the agent
3. Give client_token to one agent
4. POST /check before signing
5. Continue only on ALLOW
6. Verify receipt and intent at the signer

FAIL CLOSED

Unavailable means do not pay.

A timeout, malformed response or unreachable control plane must stop the payment or send it for approval. It must never silently become an ALLOW.

decision = control_plane.check(intent)

if decision.status != "ALLOW":
    stop_or_request_approval(decision)

signer.verify(intent, decision.receipt)
signer.sign(intent)
